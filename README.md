# Семейный атлас — код оболочки

Открытый код статического сайта с входом по паролю: шифрование и расшифровка в браузере (Web Crypto, AES-256-GCM, PBKDF2-SHA-256 600 000).
**Семейных данных, зашифрованного архива и пароля здесь нет** — они хранятся отдельно. Репозиторий нужен для открытой проверки кода (CodeQL).

- `shell.js` — вход, расшифровка, «запомнить устройство» (неизвлекаемый ключ в IndexedDB), выход.
- `sw.js` — офлайн-кэш (где разрешён service worker).
- `tools/vault.py` — проверка, смена пароля и сборка архива.
